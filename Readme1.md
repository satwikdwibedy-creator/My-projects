# 🌍 Air Quality Index (AQI) Checker

A Python script that fetches real-time AQI (Air Quality Index) data for multiple Indian cities using the **World Air Quality Index API**.

## 🚀 Features
- Fetches AQI for a predefined list of cities
- Handles missing/invalid data gracefully
- Prints results in a clean format

## 🛠 Tech Stack
- Python
- Requests
