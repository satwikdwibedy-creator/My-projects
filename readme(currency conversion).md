# 💱 Crypto Price Chatbot

An interactive command-line chatbot that fetches **real-time cryptocurrency prices** using the **CoinGecko API**.

## 🚀 Features
- Converts cryptocurrencies (BTC, ETH, DOGE, etc.) to fiat currencies (USD, INR, EUR, etc.)
- Interactive chatbot with user input
- Error handling for invalid entries

## 🛠 Tech Stack
- Python
- Requests
