# 🌦 Current Weather Info

A Python script that fetches **real-time weather conditions** for a given city using the **OpenWeather API**.

## 🚀 Features
- Fetches current weather description and temperature
- Handles errors for invalid city names
- Command-line based user input

## 🛠 Tech Stack
- Python
- Requests
