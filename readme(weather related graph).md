# 📊 Weather Forecast Graphs

A Python script that fetches a **5-day weather forecast** for a given city using the **OpenWeather API**, and visualizes the data with **Matplotlib**.

## 🚀 Features
- Fetches weather forecast (temperature, humidity, wind speed, condition)
- Saves data into a Pandas DataFrame
- Plots a line graph of temperature vs. time
- Calculates average temperature for the forecast period

## 🛠 Tech Stack
- Python
- Requests
- Pandas
- Matplotlib
- NumPy
